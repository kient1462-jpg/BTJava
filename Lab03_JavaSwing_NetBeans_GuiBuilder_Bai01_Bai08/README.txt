LAB 3 - NETBEANS GUI BUILDER
Maven project + 8 JFrame Forms (.java + .form).

Mở bằng NetBeans:
1. File -> Open Project -> chọn thư mục lab03-java-swing-gui.
2. Mở Source Packages -> vn.edu.eaut.lab3.
3. Bấm đúp Bai01HelloSwing.java, ... Bai08QuanLySinhVien.java.
4. Chọn tab Design để xem giao diện kéo-thả.
5. Chọn Source để sửa code xử lý sự kiện.

Lưu ý: các file .form là metadata của NetBeans GUI Builder. Không xóa chúng.
